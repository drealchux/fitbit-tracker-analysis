# Bellabeat Case Study: User Usage Analysis

## Mission Statement

Bellabeat, a high-tech company that manufactures health-focused smart products, wants to analyze how customers are using one of its smart devices. The goal is to identify usage patterns and gain insights into user behavior.

Using these insights, Bellabeat would like to develop high-level recommendations that can help inform and improve its marketing strategy.


# Phase 1: Ask

## Key Objectives

### 1. Identify the Business Task

Bellabeat wants to better target its marketing efforts based on how customers use its fitness-focused smart devices.

By analyzing usage patterns, the company can better understand its customers' needs and behaviors. These insights can then be used to make high-level recommendations for Bellabeat's marketing strategy.

### 2. Consider Key Stakeholders

The key stakeholders for this analysis are:

* **Urška Sršen**: Bellabeat's Co-founder and Chief Creative Officer
* **Sando Mur**: Bellabeat's Mathematician and Co-founder
* **Bellabeat's marketing analytics team**

### 3. Define the Business Task

Based on the objectives above, the business task is to identify patterns in how users interact with and use Bellabeat's smart devices. These insights can then be used to support better-informed marketing decisions and strategy.

The business task can be summarized in three question:

> **How do our users use their smart devices?**
> **How could these trends apply to Bellabeat customers?**
> **How could these trends help influence Bellabeat marketing strategy?**

# Phase 2: Prepare

## Key Objectives

### 1. Determine the Credibility of the Data

The data used for this analysis comes from the **Fitbit Fitness Tracker Data** dataset. It contains data from **30 Fitbit users**, including minute-level information on physical activity, heart rate, and sleep monitoring.

The dataset is organized into several tables, with each table representing different aspects of Fitbit device usage and user behavior. The data provides a relatively detailed view of how users interact with their devices.

However, the relatively small sample size of 30 users should be considered when interpreting the results. The findings may not necessarily represent the behavior of the broader population of smart-device users.

### 2. Sort and Filter the Data

For this analysis, the focus will be on the **daily timeframe** rather than minute-level data.

The objective is to identify high-level trends in device usage rather than analyze detailed individual performance. Therefore, the most relevant datasets are those containing:

* Daily physical activity
* Daily steps
* Daily calories burned
* Daily distance
* Daily sleep information
* Daily activity levels

Some of these datasets will need to be combined to create a more complete picture of user behavior.

The analysis will focus on identifying relationships and patterns between **daily activity, sleep, and overall device usage**. These patterns can then provide useful insights for developing recommendations for Bellabeat's marketing strategy.

## Data Preparation Approach

The preparation process will involve:

1. Reviewing the available datasets and their structures.
2. Checking for missing or inconsistent data.
3. Removing or addressing duplicate records where necessary.
4. Selecting the datasets most relevant to the business question.
5. Aggregating detailed data into daily-level measurements.
6. Combining relevant tables to create a comprehensive analysis dataset.
7. Preparing the cleaned data for analysis and visualization.



# Analysis Goal

The overall goal of the analysis is to understand **how users interact with their smart devices on a daily basis**.

In particular, the analysis will explore:

* How frequently users use their devices.
* How active users are throughout the day.
* The relationship between physical activity and sleep.
* Patterns in daily device usage.
* Differences between users with higher and lower activity levels.
* Potential behaviors that could inform Bellabeat's marketing strategy.

The findings from this analysis will ultimately be used to develop **high-level, data-driven recommendations for Bellabeat's marketing team**.
